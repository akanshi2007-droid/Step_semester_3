## 🚀 Running the Programs

1. Clone the repository:

   ```bash
   git clone https://github.com/akanshi2007-droid/Step_semester_3.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Step_semester_3
   ```

3. Compile and run any Java file:

   ```bash
   javac FileName.java
   java FileName
   ```
